# GeoG — Notes de version Play (1re publication en PRODUCTION)

Où coller : Play Console → Production → Créer une release → **Notes de version**
(500 caractères max **par langue**, les 6 langues de la fiche sont ci-dessous).

Contexte : le canal **production n'a jamais reçu de release** (seul l'alpha a vu
la 5.0.2 et l'internal la 5.3.2). Ces notes sont donc écrites comme une **note de
lancement** — elles présentent le jeu, pas le diff d'une version précédente : un
joueur qui installe depuis le Play Store n'a jamais eu de build antérieur.
