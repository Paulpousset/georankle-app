## 4. Chapitres (vidéos longues uniquement)

Colle tel quel en fin de description. Le premier chapitre **doit** être à `00:00`,
il en faut **au moins 3**, chacun d'**au moins 10 s**, sinon YouTube ne les affiche pas.

```
00:00 Intro
00:xx Rankle
00:xx Globe Géo
00:xx Drapeaux & Capitales
00:xx Multijoueur classé
00:xx Défi du jour
```

## 5. Checklist avant publication

- [ ] Langue de la vidéo renseignée (Détails → Plus d'options)
- [ ] Titre + description collés dans les 16 langues (Sous-titres → Ajouter une langue)
- [ ] Miniature 1280×720 — lisible en 120 px de large (test : réduis-la, tu dois encore lire)
- [ ] Bloc liens présent dans les 3 premières lignes
- [ ] 3 hashtags max sur Short, ≤ 10 sur vidéo longue
- [ ] Commentaire épinglé posté
- [ ] « Contenu destiné aux enfants » : **Non** (jeu tout public, mais pas made-for-kids)
- [ ] Playlist assignée (une par mode de jeu : Rankle, Globe, Drapeaux…)
- [ ] Écran de fin sur la vidéo longue → abonnement + vidéo suivante
