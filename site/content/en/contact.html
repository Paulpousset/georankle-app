Contact

GeoG is built by one person. Messages land directly with them, and get an answer — sometimes a few days later.

paul.pousset@gmail.com

Site publisher: Paul Pousset, independent developer, France.

Report an error in a question

This is the most useful message you can send. A capital that has changed, an out-of-date figure, a border drawn wrong, an alternative answer wrongly rejected: all of it is fixable.

To make the correction quick, please include where you can:

  • the game mode concerned (Flags, Capitals, Borders…);
  • the country and the exact question;
  • the answer you expected, and your source if you have one.

Ambiguous cases — countries with several capitals, disputed territories, indicators whose sources disagree — are handled one at a time; how the data is built is described on the About page.

An account problem

Forgotten password, username to change, progress not syncing between web and mobile: write in, quoting the email address linked to the account, and never send your password.

Deleting your account and all associated data is done in the app itself, from Profile → Delete my account. It is immediate and irreversible. Details are in the privacy policy.

Suggest an idea

A missing game mode, a themed challenge on a country or a region, a language you would like to play in: suggestions are read, and several features of the game came from players' messages.

Press and partnerships

For an article, an interview, classroom use or a partnership proposal, write to the same address stating the subject. High-resolution artwork from the game can be supplied on request.
