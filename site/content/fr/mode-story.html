Comment ça marche

Le mode histoire est une campagne de {{storyLevels}} niveaux disposés sur une carte qu’on remonte niveau après niveau. Chaque niveau propose une poignée de questions tirées des modes du jeu, et rapporte de une à trois étoiles selon le score obtenu. Il faut un minimum d’étoiles pour continuer, jamais la perfection.

Une difficulté qui suit la notoriété, pas le hasard

C’est ce qui distingue le mode d’une simple suite de parties. GeoG classe les {{countries}} pays par notoriété, et la campagne suit cette échelle : les premiers niveaux tirent parmi les pays que tout le monde connaît, les derniers parmi ceux que presque personne ne situe. La progression est régulière, avec une marge assez large pour qu’un niveau reste varié.

Concrètement, le niveau 1 vous demandera la France ou le Brésil ; le niveau {{storyLevels}}, Kiribati ou le Turkménistan.

Des vies, et de quoi les récupérer

Rater un niveau coûte une vie. Les vies se régénèrent avec le temps, et il est possible d’en récupérer immédiatement — c’est le seul endroit du jeu où une publicité est proposée, jamais imposée.

Hors ligne

Le mode histoire fonctionne sans connexion dans l’application mobile : la campagne entière est dérivée du numéro de niveau, sans aucun appel réseau. C’est le format à emporter en avion ou dans le métro.

La difficulté, continent par continent

Les derniers niveaux tirent beaucoup en Océanie et dans les Caraïbes : ce sont les zones qui concentrent les pays les moins connus, et où le nombre d’États est sans rapport avec leur population.

Questions fréquentes

Combien de niveaux compte le mode histoire ?
{{storyLevels}}, du plus connu au plus confidentiel. La difficulté suit la notoriété des pays, pas un tirage au hasard.
Le mode histoire est-il gratuit ?
Oui, entièrement. Les vies se régénèrent avec le temps ; une publicité facultative permet d’en récupérer immédiatement, mais elle n’est jamais imposée.
Peut-on y jouer hors ligne ?
Oui, dans l’application mobile : toute la campagne est dérivée du numéro de niveau, sans appel réseau.
Faut-il trois étoiles pour avancer ?
Non. Un seuil minimum suffit pour débloquer le niveau suivant ; les trois étoiles sont là pour ceux qui veulent tout terminer parfaitement.
